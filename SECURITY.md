# Security

Please report security problems privately through
[Report a vulnerability](https://github.com/liuy7713/YihaosNotch/security/advisories/new),
not in a public issue.

This is a personal project maintained in my spare time. I'll reply as soon as I can,
usually within a week, and credit you in the release notes if you'd like.

Only the latest release gets fixes. Download the app only from this repository's
[Releases](https://github.com/liuy7713/YihaosNotch/releases) page; builds from anywhere
else aren't mine. Each release lists the disk image's SHA-256 and the hash of the
certificate it's signed with.
